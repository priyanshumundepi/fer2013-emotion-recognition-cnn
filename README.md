# FER2013 Emotion Recognition using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) to recognize human facial emotions using the FER-2013 dataset.

## Dataset
The FER-2013 dataset contains facial images belonging to 7 emotion classes:

- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

## Model
A CNN model is used for image classification. The model processes grayscale facial images of size 48×48 pixels.

## Technologies Used
- Python
- TensorFlow
- Keras
- CNN
- Google Colab
- FER-2013 Dataset

## Objective
The objective of this project is to build a deep learning model capable of classifying facial expressions into different emotion categories.
